# Задание

Изучить жизненный цикл Activity и управление состоянием через ViewModel. Доработать Unscramble, ArtSpaceApp и Dessert Clicker, создать ActivityLifecycle и написать тесты игры.

# Выполнено

- `activitylifecycle`: вывод методов жизненного цикла в Logcat.
- `artspace`: состояние галереи и переключение картин во ViewModel.
- `dessertclicker`: состояние продаж и выбор десерта во ViewModel.
- `unscramble`: игровая логика, StateFlow и шесть тестов GameViewModel.
